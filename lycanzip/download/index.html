Requirements

  • Windows 10 version 1809 or newer, or Windows 11; 64-bit.
  • Nothing else to install. Everything LycanZip needs is in the package.
  • About 70 MB of disk space.

With a package manager

winget or Scoop (with version 1.0):

winget install Aegisulf.LycanZip
scoop install lycanzip

Check your download

Every release lists the SHA-256 of each file. In PowerShell, in the folder of the download:

Get-FileHash .\LycanZip-0.9.2-Setup.exe -Algorithm SHA256

The value must match the release page. If not, delete the file and download it again.

LycanZip can do this too: right-click the file, choose Calculate hash values… and paste the value from the release page.

“Windows protected your PC” (SmartScreen)

Only the Store version is signed with a certificate, and Windows warns about programs it has not seen often. It does not mean the file is bad. After checking the SHA-256 above, click More info, then Run anyway.

If Windows blocks files you unzip, right-click the zip first, choose Properties and tick Unblock.

The Microsoft Store version

The same program as a Store package, signed and updated by Windows. It is the only version with the new Windows 11 right-click menu: Windows only allows that for signed packages. The links will be here when it passes the Store review.

Uninstall

Installer: Settings → Apps. Zip: delete the folder (and %LOCALAPPDATA%\LycanZip for the standard zip). If you switched on the Explorer menu or file associations, switch them off in the settings first. Store version: remove it in Settings → Apps.
