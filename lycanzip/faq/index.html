FAQ

Windows says “Windows protected your PC”. Is the download safe?

Only the Store version is code-signed, and SmartScreen warns about programs it has not seen often. Check the SHA-256 of your download against the release page (how), then choose More info → Run anyway. The whole source is public.

My antivirus lists “lycanzip-cli.exe” as an “affected item” after a scan. Is LycanZip infected?

No. When you scan an archive, LycanZip hands the content of each file to your antivirus through the Windows Antimalware Scan Interface (AMSI). Some antivirus programs then name the program that handed it over as the “affected item”. LycanZip’s own message names the file that was really reported.

Installer, portable or Store?

The installer is the easy one and can update itself. Portable keeps its settings next to the program (a USB stick). The Store version is updated by Windows.

Can I have the Store version and another one at the same time?

Yes, but one is enough. When the Store version is installed, it provides the right-click menu and the file types: the installer, zip and portable versions switch their own off when they start, so File Explorer shows LycanZip once, and they say so one time. Each copy keeps its own settings. To keep only one, remove the other in Settings → Apps → Installed apps (a portable folder can simply be deleted).

Where are the entries in the Explorer menu?

Switch them on in Settings → File Explorer. On Windows 10 they are in the right-click menu. On Windows 11 the installer and zip versions show them under Show more options (or Shift+F10); only the Store version shows them in the new top-level menu. Each entry can be switched off. There is a right-drag menu too.

Why is the new Windows 11 menu only in the Store version?

Windows 11 only lets a signed package add entries to its new top-level menu. Only the Store version is signed (by the Store itself); the installer and the zip versions are not, because a code-signing certificate costs money and LycanZip is free. They use the classic menu instead, with the same entries.

How do I make LycanZip open archives?

Register the file types in Settings → File Explorer, then choose LycanZip once in Windows Settings → Apps → Default apps. Windows does not let a program make itself the default.

Which formats can LycanZip open and create?

Open: everything 7-Zip reads: zip, 7z, rar (also split), tar, gz, xz, bz2, iso, cab, wim and more. Create: zip, 7z, tar, tar.gz, tar.xz, tar.bz2, iso. RAR can only be extracted: the RAR format may not be written by programs that use 7-Zip code.

The file names in an old zip file are garbled.

LycanZip detects Big5, GBK, Shift-JIS, EUC-KR and UTF-8 by itself. If it guessed wrong, pick the encoding with the button at the top right of the archive view.

Is my password safe? Can a lost password be recovered?

zip uses AES-256 by default, and 7z can encrypt the file names too. LycanZip never stores or sends passwords. A lost password cannot be recovered.

Does LycanZip send anything over the internet?

Nothing about you or your files. See the privacy policy.

What does “Look up on VirusTotal” do? Is the file uploaded?

Only the SHA-256 is sent, as part of the web address, and the VirusTotal page of that hash opens in your browser. The file is never uploaded. If VirusTotal does not know the hash, that only means nobody uploaded that exact file: it does not mean the file is safe.

Something does not work. Where do I report it?

Open an issue on GitHub and add the output of lycanzip-cli info (version, settings place, log folder).
