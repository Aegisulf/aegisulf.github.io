What it does

Everything an archiver should do

Open zip, 7z, rar, tar, iso and dozens more. Create zip, 7z and tar with AES-256 passwords. Browse, search, drag files out to Explorer, and convert an archive to another format; the original stays until you delete it.

File names come out right

Old zip files with Big5, GBK, Shift-JIS or EUC-KR names are detected automatically. Upgrade such an archive and its names are stored in UTF-8, so they read correctly on any PC; the data is copied as it is.

Look inside without unpacking

Select a file and the preview pane shows it: pictures, text, PDF and audio. Pictures also open in a viewer with a thumbnail strip, zoom and animations. Music plays in a built-in player that shows the tags.

A reading mode for comic books

A whole book in order, across folders, two pages side by side and right to left if you like. The page is remembered for each book. .cbz, .cbr, .cb7 and .cbt open in it directly.

A password manager that stays on your PC

Passwords that worked in this session and saved passwords are tried before you are asked. Saved ones are encrypted for your Windows account, with an optional master password. Nothing is sent anywhere.

The Windows 11 right-click menu Store version only

Entries right in the top level of the Windows 11 menu, no “Show more options” first. Windows only allows this for a signed package, so it comes with the Microsoft Store version. The other versions use the classic menu.

Dark, light, your colour

Light or dark, six accent colours, or just follow Windows. Optional sound effects (two sets) and animations, which you can switch off.

Change an archive in place

Add, delete, rename, replace inside zip, 7z and tar, or edit a file in your own editor and save it back. Done on a safe copy.

Safe by design

No telemetry, no ads, nothing collected. And three ways to check what you are about to open:

Antivirus scan

Scan an archive with your own antivirus through Windows AMSI, without unpacking it to disk.

SHA-256 check

Hash any file, folder or archive. Verify a .sha256 file with a double click.

VirusTotal lookup

One click opens the VirusTotal page of the file’s hash. Only the hash is sent, never the file.

Unsafe paths are refused, links are not followed, and compression bombs are caught.
