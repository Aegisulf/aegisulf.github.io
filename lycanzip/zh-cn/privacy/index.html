隐私政策

最后更新：2026 年 10 月 25 日。适用于 LycanZip 程序（安装程序、zip 安装包和 Microsoft Store 版）以及本网站。这是英文版的翻译；如有出入，以英文版为准。

简单说

LycanZip 不收集、不在服务器上存储、不出售也不分享任何个人数据。没有遥测、没有广告、没有跟踪、没有账号。完全可以离线使用。

哪些东西留在你的电脑上

  • 设置和模板：你的选择（主题、语言、压缩模板、最近使用的文件夹）保存在你电脑上的文件里：便携版在程序文件夹，标准版和 Store 版在 %LOCALAPPDATA%\LycanZip。
  • 日志文件：程序做了什么的简短记录（错误、版本）。只记文件名；只有你自己开启“含完整路径的详细日志”时才会写入完整路径。它不会发送到任何地方。你可以阅读和删除它（lycanzip-cli info 会显示位置）。
  • 崩溃报告：程序崩溃时会在你的电脑上写一份报告，方便你需要时附在问题报告里。不会上传任何东西。
  • 临时文件：从压缩包打开的文件会解压到临时文件夹，之后删除。

你的文件

LycanZip 只读写你要它处理的文件。它不会上传这些文件，也不会把文件名或内容发送到任何地方。如果你使用病毒扫描，文件内容会通过 Windows 的 Antimalware Scan Interface 交给你电脑上安装的杀毒软件；那个软件做什么，由它自己的厂商说明。

网络请求

LycanZip 本身不发出任何网络请求，只有一个可选的例外：检查新版本。开启它的时候（默认是关的；Microsoft Store 版不会检查，由 Store 更新），程序会下载一个很小的公开文件 aegisulf.com/lycanzip/latest.json，内容是最新的版本号。请求里没有标识符、没有设置，也没有任何关于你的电脑或文件的数据。已安装的版本（由安装程序安装）如果开了这个检查，也会自己从 aegisulf.com/lycanzip/updates/ 下载更新、检查签名，并且只在你选择时才安装；那个请求和上面的一样匿名。和任何网络请求一样，存放这个文件的服务器（GitHub Pages）会在它自己的日志里看到请求的 IP 地址；LycanZip 无法访问那些日志。

第二种是你自己发起的：在 VirusTotal 查询（在“更多选项”、压缩包内文件的菜单和哈希值窗口里）。LycanZip 会计算文件的 SHA-256，并在你的浏览器中打开 virustotal.com 上该哈希值的页面。网址里只有哈希值；文件不会被上传，LycanZip 也不使用 VirusTotal 账号或 API。VirusTotal 和你的浏览器看到的请求，和你打开任何网页时一样。如果 VirusTotal 不认识这个哈希值，不代表文件安全。

本网站

本网站没有 cookie、没有分析工具，也没有第三方的脚本或字体。页面由 GitHub Pages 提供，它可能依据 GitHub 的隐私声明保留技术日志。

儿童

LycanZip 不收集任何人的数据，包括儿童。

变更和联系

如果本政策有变更，上面的日期会更新，新的内容会发布在这里。有问题请到 GitHub 提一个 issue。
