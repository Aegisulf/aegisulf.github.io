LycanZip

LycanZip 是以 MIT 许可发布的自由软件。只要附上许可文本，你可以使用、复制、修改和分享它，包括商业用途。不附带任何担保。

7-Zip

压缩和解压由 Igor Pavlov 的 7-Zip 引擎负责，以独立的库（7z.dll）加载，连同它的许可文本一起放在安装包里。7-Zip 的许可是 GNU LGPL，而读取 RAR 压缩包的代码带有“unRAR 限制”：可以用来读取 RAR 压缩包，但不能用来开发创建 RAR 压缩包的软件。LycanZip 只解压 RAR。LycanZip 并非 7-Zip 作者所制作、认可或支持。

Windows App SDK 和 WinUI 3

界面使用 Microsoft 的 Windows App SDK 和 WinUI 3（MIT 许可）。本网站上的“Windows”、“Microsoft Store”和其他产品名称属于其所有者。
