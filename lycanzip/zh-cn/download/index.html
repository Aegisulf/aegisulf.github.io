系统要求

  • Windows 10 1809 及以上，或 Windows 11；64 位。
  • 无需另外安装任何东西。LycanZip 需要的都在安装包里。
  • 约 70 MB 磁盘空间。

用包管理器安装

winget 或 Scoop（1.0 版起提供）：

winget install Aegisulf.LycanZip
scoop install lycanzip

校验你下载的文件

每个版本都列出各文件的 SHA-256。在下载文件所在的文件夹打开 PowerShell，运行：

Get-FileHash .\LycanZip-0.9.7-Setup.exe -Algorithm SHA256

显示的值必须和发布页面上的一致。不一致就删掉文件，重新下载。

LycanZip 本身也能做：在文件上右键，选“计算哈希值…”，再粘贴发布页面上的值。

“Windows 已保护你的电脑”（SmartScreen）

只有 Store 版有证书签名，而 Windows 会对不常见的程序发出警告。这不代表文件有问题。确认上面的 SHA-256 之后，点“更多信息”，再点“仍要运行”。

如果 Windows 拦住你解压出来的文件，请先在 zip 上右键，选“属性”，勾选“解除锁定”。

Microsoft Store 版

同一个程序的 Store 安装包，由 Windows 签名并负责更新。它是唯一有 Windows 11 新式右键菜单的版本：Windows 只允许签名过的安装包这么做。通过 Store 审核后，链接会放在这里。

卸载

安装程序：到“设置 → 应用”。Zip：删除文件夹（标准版另外删除 %LOCALAPPDATA%\LycanZip）。如果你开启过资源管理器菜单或文件关联，请先在设置里关掉。Store 版：在“设置 → 应用”中卸载。
