常见问题

Windows 提示“Windows 已保护你的电脑”。这个下载安全吗？

只有 Store 版有代码签名，而 SmartScreen 会对不常见的程序发出警告。请核对下载文件的 SHA-256 与发布页面是否一致（方法），再选“更多信息 → 仍要运行”。完整的源代码是公开的。

扫描后，我的杀毒软件把“lycanzip-cli.exe”列为“受影响的项目”。LycanZip 中毒了吗？

没有。扫描压缩包时，LycanZip 会通过 Windows 的 Antimalware Scan Interface（AMSI），把每个文件的内容交给你的杀毒软件。有些杀毒软件会把交出内容的程序列为“受影响的项目”。LycanZip 自己的提示会指出真正被报告的文件。

安装程序、便携版还是 Store 版？

安装程序最简单，而且能自动更新。便携版把设置放在程序旁边（适合 U 盘）。Store 版由 Windows 更新。

可以同时安装 Store 版和其他版本吗？

可以，但装一份就够了。装了 Store 版时，右键菜单与文件类型由 Store 版提供：安装程序、zip 与便携版启动时会把自己的关掉，文件资源管理器只会显示一个 LycanZip，并提示一次。每一份的设置各自独立。只想保留一份，就到设置 → 应用 → 已安装的应用卸载另一份（便携版直接删除文件夹即可）。

资源管理器的菜单在哪里？

在“设置 → 文件资源管理器”中开启。在 Windows 10 上，它们在右键菜单里。在 Windows 11 上，安装程序和 zip 版把它们放在“显示更多选项”里（或按 Shift+F10）；只有 Store 版会显示在新式的第一层菜单。每一项都可以关掉。另外还有按住右键拖拽的菜单。

为什么 Windows 11 新式菜单只有 Store 版有？

Windows 11 只让签名过的安装包把项目加进新式的第一层菜单。只有 Store 版有签名（由 Store 签），安装程序和 zip 版没有，因为代码签名证书要花钱，而 LycanZip 是免费的。它们改用传统菜单，项目相同。

怎么让 LycanZip 来打开压缩包？

在“设置 → 文件资源管理器”中注册文件类型，再到“Windows 设置 → 应用 → 默认应用”里选一次 LycanZip。Windows 不允许程序自己设为默认。

LycanZip 能打开和创建哪些格式？

打开：7-Zip 能读的都行：zip、7z、rar（含分卷）、tar、gz、xz、bz2、iso、cab、wim 等。创建：zip、7z、tar、tar.gz、tar.xz、tar.bz2、iso。RAR 只能解压：使用 7-Zip 代码的程序不能写出 RAR 格式。

旧 zip 文件里的文件名是乱码。

LycanZip 会自动识别 Big5、GBK、Shift-JIS、EUC-KR 和 UTF-8。如果猜错了，用压缩包视图右上角的按钮选择编码。

我的密码安全吗？忘记密码能找回来吗？

zip 默认使用 AES-256，7z 还能连文件名一起加密。LycanZip 不会保存或发送密码。忘记的密码无法找回。

LycanZip 会通过网络发送东西吗？

不会发送任何关于你或你的文件的数据。详见隐私政策。

“在 VirusTotal 查询”做了什么？文件会被上传吗？

只会发送 SHA-256（放在网址里），并在浏览器中打开该哈希值的 VirusTotal 页面。文件绝不会被上传。如果 VirusTotal 不认识这个哈希值，只代表没有人上传过一模一样的文件，不代表文件安全。

有东西不能用。到哪里报告？

到 GitHub 提一个 issue，并附上 lycanzip-cli info 的输出（版本、设置位置、日志文件夹）。
