개인정보 처리방침

최종 업데이트: 2026년 11월 1일. LycanZip 프로그램(설치 프로그램, zip 패키지, Microsoft Store 버전)과 이 웹사이트에 적용됩니다. 이 문서는 영어판의 번역이며, 차이가 있으면 영어판이 우선합니다.

요약

LycanZip은 개인 데이터를 수집하거나 서버에 저장하거나 판매하거나 공유하지 않습니다. 원격 분석, 광고, 추적, 계정이 없습니다. 완전히 오프라인으로 작동합니다.

PC에 남는 것

  • 설정과 템플릿: 선택한 내용(테마, 언어, 압축 템플릿, 최근 폴더)은 PC의 파일에 저장됩니다. 위치는 프로그램 폴더(포터블) 또는 %LOCALAPPDATA%\LycanZip(표준 및 Store)입니다.
  • 저장된 암호: 저장하기로 선택한 암호만 Windows 계정에 맞게 암호화되어(마스터 암호 선택 가능) PC의 파일에 저장됩니다. 어디로도 전송되지 않습니다.
  • 로그 파일: 프로그램이 한 일의 짧은 기록(오류, 버전)입니다. 파일 이름만 사용하며, 전체 경로는 전체 경로가 포함된 자세한 로그를 직접 켠 경우에만 기록됩니다. 어디로도 전송되지 않습니다. 읽고 삭제할 수 있습니다(lycanzip-cli info가 위치를 알려 줍니다).
  • 충돌 보고서: 프로그램이 충돌하면 PC에 보고서를 작성하며, 원하면 버그 신고에 첨부할 수 있습니다. 아무것도 업로드되지 않습니다.
  • 임시 파일: 압축 파일에서 연 파일은 임시 폴더에 풀린 뒤 제거됩니다.

사용자의 파일

LycanZip은 요청받은 파일을 읽고 씁니다. 파일을 업로드하거나 이름이나 내용을 어디로도 보내지 않습니다. 바이러스 검사를 사용하면 파일 내용이 Windows AMSI(Antimalware Scan Interface)를 통해 PC에 설치된 백신으로 전달됩니다. 그 프로그램의 동작은 해당 공급업체가 설명합니다.

네트워크 요청

LycanZip은 스스로 네트워크 요청을 하지 않습니다. 선택적인 예외는 하나, 새 버전 확인입니다. 이 기능을 켜면(기본값은 꺼짐. Microsoft Store 버전은 확인하지 않고 Store가 업데이트합니다) 최신 버전 번호를 알려 주는 작은 공개 파일 aegisulf.com/lycanzip/latest.json을 다운로드합니다. 요청에는 식별자, 설정, PC나 파일에 관한 정보가 없습니다. 설치 프로그램으로 설치한 사본에서 이 확인을 켜면 업데이트도 aegisulf.com/lycanzip/updates/에서 다운로드하고 서명을 확인한 뒤 선택할 때만 설치합니다. 이 요청도 위와 마찬가지로 익명입니다. 다른 웹 요청과 마찬가지로 파일을 호스팅하는 서버(GitHub Pages)는 자체 로그에서 요청의 IP 주소를 볼 수 있으며, LycanZip은 그 로그에 접근할 수 없습니다.

두 번째는 직접 시작하는 경우입니다: VirusTotal에서 조회(추가 옵션, 압축 파일 속 파일의 메뉴, 해시 값 창에 있습니다). LycanZip은 파일의 SHA-256을 계산하고 브라우저에서 해당 해시의 virustotal.com 페이지를 엽니다. 주소에는 해시만 들어가고, 파일은 업로드되지 않으며, VirusTotal 계정이나 API를 사용하지 않습니다. VirusTotal과 브라우저는 다른 웹 페이지를 열 때처럼 요청을 봅니다. VirusTotal이 해시를 모른다고 해서 파일이 안전하다는 뜻은 아닙니다.

이 웹사이트

이 사이트에는 쿠키, 분석 도구, 타사 스크립트나 글꼴이 없습니다. 페이지는 GitHub Pages가 제공하며, GitHub 개인정보 보호 정책에 설명된 대로 기술 로그를 보관할 수 있습니다.

어린이

LycanZip은 어린이를 포함해 누구의 데이터도 수집하지 않습니다.

변경 및 문의

이 방침이 바뀌면 위의 날짜가 바뀌고 새 내용이 여기에 게시됩니다. 질문은 GitHub에 issue를 열어 주세요.
