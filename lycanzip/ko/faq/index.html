자주 묻는 질문

“Windows의 PC 보호”라는 메시지가 나옵니다. 다운로드는 안전한가요?

코드 서명이 있는 것은 Store 버전뿐이며, SmartScreen은 자주 보지 못한 프로그램에 경고를 표시합니다. 다운로드한 파일의 SHA-256을 확인한 뒤(방법) 추가 정보 → 실행을 선택하세요. 소스 코드는 모두 공개되어 있습니다.

검사 후 백신이 “lycanzip-cli.exe”를 “영향을 받는 항목”으로 표시합니다. LycanZip이 감염되었나요?

아닙니다. 압축 파일을 검사할 때 LycanZip은 Windows AMSI(Antimalware Scan Interface)를 통해 각 파일의 내용을 백신에 전달합니다. 일부 백신은 내용을 전달한 프로그램의 이름을 “영향을 받는 항목”으로 표시합니다. 실제로 보고된 파일은 LycanZip의 메시지에 표시됩니다.

설치 프로그램, 포터블, Store 중 무엇이 좋은가요?

설치 프로그램은 간편하고 스스로 업데이트할 수 있습니다. 포터블은 설정을 프로그램 옆에 저장합니다(USB 메모리용). Store 버전은 Windows가 업데이트합니다.

Store 버전과 다른 버전을 함께 쓸 수 있나요?

가능하지만 하나면 충분합니다. Store 버전이 설치되어 있으면 오른쪽 클릭 메뉴와 파일 형식은 Store 버전이 제공합니다. 설치 프로그램, zip, 포터블 버전은 시작할 때 자신의 것을 끄므로 파일 탐색기에는 LycanZip이 한 번만 표시되며, 이를 한 번 알려 줍니다. 설정은 사본마다 따로 저장됩니다. 하나만 남기려면 다른 하나를 설정 → 앱 → 설치된 앱에서 제거하세요(포터블 폴더는 그냥 삭제하면 됩니다).

탐색기 메뉴 항목은 어디에 있나요?

LycanZip의 설정 → 파일 탐색기에서 켭니다. Windows 10에서는 오른쪽 클릭 메뉴에 표시됩니다. Windows 11에서는 설치 프로그램과 zip 버전이 더 많은 옵션 표시(또는 Shift+F10) 안에 표시되며, 새 최상위 메뉴에는 Store 버전만 표시됩니다. 항목은 각각 끌 수 있습니다. 오른쪽 끌기 메뉴도 있습니다.

새 Windows 11 메뉴가 왜 Store 버전에만 있나요?

Windows 11은 새 최상위 메뉴에 항목을 추가하는 것을 서명된 패키지에만 허용합니다. 서명된 것은 Store 버전뿐(Store가 직접 서명)입니다. 코드 서명 인증서는 유료이고 LycanZip은 무료이므로 설치 프로그램과 zip 버전에는 서명이 없습니다. 이들은 같은 항목을 기존 메뉴에서 제공합니다.

압축 파일을 LycanZip으로 열려면 어떻게 하나요?

LycanZip의 설정 → 파일 탐색기에서 파일 형식을 등록한 다음 Windows 설정 → 앱 → 기본 앱에서 LycanZip을 한 번 선택하세요. Windows는 프로그램이 스스로 기본 앱이 되는 것을 허용하지 않습니다.

어떤 형식을 열고 만들 수 있나요?

열기: 7-Zip이 읽는 모든 형식(zip, 7z, rar(분할 포함), tar, gz, xz, bz2, iso, cab, wim 등). 만들기: zip, 7z, tar, tar.gz, tar.xz, tar.bz2, iso. RAR은 압축 풀기만 가능합니다. 7-Zip 코드를 사용하는 프로그램은 RAR 형식을 쓸 수 없습니다.

오래된 zip 파일의 파일 이름이 깨져 보입니다.

LycanZip은 Big5, GBK, Shift-JIS, EUC-KR, UTF-8을 자동으로 감지합니다. 잘못 감지했다면 압축 파일 화면 오른쪽 위의 버튼에서 인코딩을 선택하세요.

암호는 안전한가요? 잊어버린 암호를 복구할 수 있나요?

zip은 기본으로 AES-256을 사용하고, 7z는 파일 이름도 암호화할 수 있습니다. LycanZip은 암호를 어디로도 보내지 않으며, 요청할 때만 저장합니다. 저장된 암호는 Windows 계정에 맞게 암호화되고 마스터 암호도 설정할 수 있습니다. 잊어버린 암호는 복구할 수 없습니다.

LycanZip이 인터넷으로 무언가를 보내나요?

사용자나 파일에 관한 것은 아무것도 보내지 않습니다. 개인정보 처리방침을 참고하세요.

“VirusTotal에서 조회”는 무엇을 하나요? 파일이 업로드되나요?

웹 주소의 일부로 SHA-256만 전송되며 해당 해시의 VirusTotal 페이지가 브라우저에서 열립니다. 파일은 업로드되지 않습니다. VirusTotal이 해시를 모른다면 그 파일을 아무도 올리지 않았다는 뜻일 뿐, 안전하다는 뜻은 아닙니다.

제대로 작동하지 않습니다. 어디에 신고하나요?

GitHub에 issue를 열고 lycanzip-cli info의 출력(버전, 설정 위치, 로그 폴더)을 첨부해 주세요.

LycanZip은 MIT 라이선스의 자유 소프트웨어입니다. 7-Zip 엔진(GNU LGPL, unRAR 제한 포함)을 사용하며, 7-Zip 개발자가 만들거나 보증한 것이 아닙니다. 라이선스
