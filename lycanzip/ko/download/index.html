LycanZip 다운로드

최신 버전: 1.1.1 (새로운 내용). Windows 10(1809 이상) 및 Windows 11, 64비트.

Microsoft Store Windows 11에 권장

새 Windows 11 오른쪽 클릭 메뉴를 지원하는 유일한 버전입니다. 서명되어 있고 Windows가 업데이트합니다.

Store에서 열기 Store 설치 프로그램

설치 프로그램 Windows 10에 권장

클릭 한 번으로 설치하며 관리자 권한이 필요 없습니다. 허용하면 스스로 업데이트합니다.

다운로드 (.exe)

SHA-256f41849968410e6410c36d8e3f750cc1d1c4cdc61b924d6b51abc503cd917d412

표준 zip

같은 프로그램이며 설정은 사용자 프로필에 저장됩니다.

다운로드 (.zip)

SHA-25681213802e07cc88edb839359d1f7bbbef4dcc53a5ce50bfdc90c709e39cc3380

포터블 zip

원하는 곳에 압축을 풀고 LycanZip.exe를 실행하세요. 설정은 같은 폴더에 저장되어 USB 메모리에도 좋습니다.

SHA-2567fcd028d8c7f73779c09d8fc503ace3d1da3a8a431c8f16a75296d7080c4acfd

모든 파일과 이전 버전: GitHub 릴리스.

시스템 요구 사항

  • Windows 10 버전 1809 이상 또는 Windows 11, 64비트.
  • 따로 설치할 것이 없습니다. 필요한 것은 모두 패키지에 들어 있습니다.
  • 디스크 공간 약 70MB.

winget으로 설치

Windows의 패키지 관리자 winget:

winget install Aegisulf.LycanZip

다운로드 확인

각 파일의 SHA-256은 위 버튼 아래(및 릴리스 페이지)에 표시되어 있습니다. 다운로드한 폴더의 PowerShell에서:

Get-FileHash .\LycanZip-1.1.1-Setup.exe -Algorithm SHA256

값이 위의 값과 일치해야 합니다. 다르면 파일을 삭제하고 다시 다운로드하세요.

LycanZip으로도 확인할 수 있습니다. 파일을 마우스 오른쪽 버튼으로 클릭하고 해시 값 계산…을 선택한 뒤 위의 값을 붙여 넣으세요.

“Windows의 PC 보호”(SmartScreen)

인증서로 서명된 것은 Store 버전뿐이며, Windows는 자주 보지 못한 프로그램에 경고를 표시합니다. 파일에 문제가 있다는 뜻은 아닙니다. 위의 SHA-256을 확인한 뒤 추가 정보, 실행을 차례로 클릭하세요.

압축을 푼 파일을 Windows가 차단하면 먼저 zip을 마우스 오른쪽 버튼으로 클릭하고 속성을 선택해 차단 해제를 선택하세요.

Microsoft Store 버전

같은 프로그램의 Store 패키지로, 서명되어 있고 Windows가 업데이트합니다. 새 Windows 11 오른쪽 클릭 메뉴를 지원하는 유일한 버전입니다. Windows가 이를 서명된 패키지에만 허용하기 때문입니다.

제거

설치 프로그램: 설정 → 앱. zip: 폴더를 삭제합니다(표준 zip은 %LOCALAPPDATA%\LycanZip도). 탐색기 메뉴나 파일 연결을 켰다면 먼저 LycanZip 설정에서 끄세요. Store 버전: 설정 → 앱에서 제거합니다.

LycanZip은 MIT 라이선스의 자유 소프트웨어입니다. 7-Zip 엔진(GNU LGPL, unRAR 제한 포함)을 사용하며, 7-Zip 개발자가 만들거나 보증한 것이 아닙니다. 라이선스
