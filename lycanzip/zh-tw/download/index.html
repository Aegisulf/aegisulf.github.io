系統需求

  • Windows 10 1809 以上，或 Windows 11；64 位元。
  • 不需要另外安裝任何東西。LycanZip 需要的都在套件裡。
  • 約 70 MB 磁碟空間。

用套件管理員安裝

winget 或 Scoop（1.0 版起提供）：

winget install Aegisulf.LycanZip
scoop install lycanzip

驗證你下載的檔案

每個版本都列出各檔案的 SHA-256。在下載檔案所在的資料夾開啟 PowerShell，執行：

Get-FileHash .\LycanZip-0.9.2-Setup.exe -Algorithm SHA256

顯示的值必須和發行頁面上的一致。不一致就刪掉檔案，重新下載。

LycanZip 本身也能做：在檔案上按右鍵，選「計算雜湊值…」，再貼上發行頁面上的值。

「Windows 已保護您的電腦」（SmartScreen）

只有 Store 版有憑證簽章，而 Windows 會對不常見的程式發出警告。這不代表檔案有問題。確認上面的 SHA-256 之後，按「其他資訊」，再按「仍要執行」。

如果 Windows 擋住你解壓縮出來的檔案，請先在 zip 上按右鍵，選「內容」，勾選「解除封鎖」。

Microsoft Store 版

同一個程式的 Store 套件，由 Windows 簽章並負責更新。它是唯一有 Windows 11 新式右鍵選單的版本：Windows 只允許簽章過的套件這麼做。通過 Store 審核後，連結會放在這裡。

解除安裝

安裝程式：到「設定 → 應用程式」。Zip：刪除資料夾（標準版另外刪除 %LOCALAPPDATA%\LycanZip）。如果你開啟過檔案總管選單或檔案關聯，請先在設定裡關掉。Store 版：在「設定 → 應用程式」移除。
