下載 LycanZip

最新版本：1.0.0（更新內容，英文）。Windows 10（1809 以上）與 Windows 11，64 位元。

Microsoft Store Windows 11 建議使用

唯一有 Windows 11 新式右鍵選單的版本。由 Windows 簽章並負責更新。

在 Store 開啟 Store 安裝程式

安裝程式 Windows 10 建議使用

一鍵安裝，不需要系統管理員權限。你同意的話，它會自己更新。

下載 (.exe)

SHA-256e05cba46fac2f3c5762451a9dea2b1e5c039a2fd37dc597aeba44176b895df7f

標準版 zip

同一個程式，設定放在你的使用者資料夾。

下載 (.zip)

SHA-256ea67f9fbe537c9e9c2dbdb6a0dfc26ba496835ec7876af1de987b3d37387039f

可攜版 zip

解壓縮到任何地方，執行 LycanZip.exe。設定留在同一個資料夾，適合放在隨身碟。

下載 (.zip)

SHA-25619ef5ff6f4be5b66270a680dd6046a93d3b109120ad52d9042a63deb732fce16

所有檔案與舊版本：GitHub 上的發行頁面。

系統需求

  • Windows 10 1809 以上，或 Windows 11；64 位元。
  • 不需要另外安裝任何東西。LycanZip 需要的都在套件裡。
  • 約 70 MB 磁碟空間。

用 winget 安裝

winget（Windows 內建的套件管理員）：

winget install Aegisulf.LycanZip

驗證你下載的檔案

各檔案的 SHA-256 列在上面的下載按鈕下方（發行頁面上也有）。在下載檔案所在的資料夾開啟 PowerShell，執行：

Get-FileHash .\LycanZip-1.0.0-Setup.exe -Algorithm SHA256

顯示的值必須和上面列出的一致。不一致就刪掉檔案，重新下載。

LycanZip 本身也能做：在檔案上按右鍵，選「計算雜湊值…」，再貼上上面列出的值。

「Windows 已保護您的電腦」（SmartScreen）

只有 Store 版有憑證簽章，而 Windows 會對不常見的程式發出警告。這不代表檔案有問題。確認上面的 SHA-256 之後，按「其他資訊」，再按「仍要執行」。

如果 Windows 擋住你解壓縮出來的檔案，請先在 zip 上按右鍵，選「內容」，勾選「解除封鎖」。

Microsoft Store 版

同一個程式的 Store 套件，由 Windows 簽章並負責更新。它是唯一有 Windows 11 新式右鍵選單的版本：Windows 只允許簽章過的套件這麼做。通過 Store 審核後，連結會放在這裡。

解除安裝

安裝程式：到「設定 → 應用程式」。Zip：刪除資料夾（標準版另外刪除 %LOCALAPPDATA%\LycanZip）。如果你開啟過檔案總管選單或檔案關聯，請先在設定裡關掉。Store 版：在「設定 → 應用程式」移除。
