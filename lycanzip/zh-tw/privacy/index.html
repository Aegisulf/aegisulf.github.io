隱私權政策

最後更新：2026 年 10 月 26 日。適用於 LycanZip 程式（安裝程式、zip 套件與 Microsoft Store 版）以及本網站。這是英文版的翻譯；如有出入，以英文版為準。

簡單說

LycanZip 不蒐集、不在伺服器上儲存、不販賣也不分享任何個人資料。沒有遙測、沒有廣告、沒有追蹤、沒有帳號。完全可以離線使用。

哪些東西留在你的電腦上

  • 設定與範本：你的選擇（主題、語言、壓縮範本、最近使用的資料夾）存在你電腦上的檔案裡：可攜版在程式資料夾，標準版與 Store 版在 %LOCALAPPDATA%\LycanZip。
  • 記錄檔：程式做了什麼的簡短記錄（錯誤、版本）。只記檔名；只有你自己開啟「含完整路徑的詳細記錄」時才會寫入完整路徑。它不會傳送到任何地方。你可以閱讀與刪除它（lycanzip-cli info 會顯示位置）。
  • 當機報告：程式當機時會在你的電腦上寫一份報告，方便你需要時附在問題回報裡。不會上傳任何東西。
  • 暫存檔：從壓縮檔開啟的檔案會解壓縮到暫存資料夾，之後移除。

你的檔案

LycanZip 只讀寫你要它處理的檔案。它不會上傳這些檔案，也不會把檔名或內容傳到任何地方。如果你使用病毒掃描，檔案內容會透過 Windows 的 Antimalware Scan Interface 交給你電腦上安裝的防毒軟體；那個軟體做什麼，由它自己的廠商說明。

網路請求

LycanZip 本身不發出任何網路請求，只有一個選用的例外：檢查新版本。開啟它的時候（預設是關的；Microsoft Store 版不會檢查，由 Store 更新），程式會下載一個很小的公開檔案 aegisulf.com/lycanzip/latest.json，內容是最新的版本號碼。請求裡沒有識別碼、沒有設定，也沒有任何關於你的電腦或檔案的資料。已安裝的版本（由安裝程式安裝）如果開了這個檢查，也會自己從 aegisulf.com/lycanzip/updates/ 下載更新、檢查簽章，並且只在你選擇時才安裝；那個請求和上面的一樣匿名。和任何網路請求一樣，放這個檔案的伺服器（GitHub Pages）會在它自己的記錄裡看到請求的 IP 位址；LycanZip 無法存取那些記錄。

第二種是你自己發起的：在 VirusTotal 查詢（在「更多選項」、壓縮檔內檔案的選單與雜湊值視窗裡）。LycanZip 會計算檔案的 SHA-256，並在你的瀏覽器開啟 virustotal.com 上該雜湊值的頁面。網址裡只有雜湊值；檔案不會被上傳，LycanZip 也不使用 VirusTotal 帳號或 API。VirusTotal 與你的瀏覽器看到的請求，和你開啟任何網頁時一樣。如果 VirusTotal 不認得這個雜湊值，不代表檔案安全。

本網站

本網站沒有 cookie、沒有分析工具，也沒有第三方的指令碼或字型。頁面由 GitHub Pages 提供，它可能依 GitHub 的隱私權聲明保留技術記錄。

兒童

LycanZip 不蒐集任何人的資料，包括兒童。

變更與聯絡

如果本政策有變更，上面的日期會更新，新的內容會發佈在這裡。有問題請到 GitHub 開一個 issue。
