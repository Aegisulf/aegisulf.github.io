LycanZip

LycanZip 是以 MIT 授權發佈的自由軟體。只要附上授權文字，你可以使用、複製、修改與分享它，包括商業用途。不附任何保證。

7-Zip

壓縮與解壓縮由 Igor Pavlov 的 7-Zip 引擎負責，以獨立的函式庫（7z.dll）載入，連同它的授權文字一起放在套件裡。7-Zip 的授權是 GNU LGPL，而讀取 RAR 壓縮檔的程式碼帶有「unRAR 限制」：可以用來讀取 RAR 壓縮檔，但不能用來開發建立 RAR 壓縮檔的軟體。LycanZip 只解壓縮 RAR。LycanZip 並非 7-Zip 作者所製作、背書或支援。

Windows App SDK 與 WinUI 3

介面使用 Microsoft 的 Windows App SDK 與 WinUI 3（MIT 授權）。本網站上的「Windows」、「Microsoft Store」與其他產品名稱屬於其所有人。

完整清單

所有元件與其授權的完整清單，在每個套件的 THIRD_PARTY.md 檔與 licenses 資料夾裡，也在原始碼倉庫。
