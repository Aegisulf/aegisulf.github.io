常見問題

Windows 說「Windows 已保護您的電腦」。這個下載安全嗎？

只有 Store 版有程式碼簽章，而 SmartScreen 會對不常見的程式發出警告。請核對下載檔案的 SHA-256 與發行頁面是否一致（方法），再選「其他資訊 → 仍要執行」。完整的原始碼是公開的。

掃描後，我的防毒軟體把「lycanzip-cli.exe」列為「受影響的項目」。LycanZip 中毒了嗎？

沒有。掃描壓縮檔時，LycanZip 會透過 Windows 的 Antimalware Scan Interface（AMSI），把每個檔案的內容交給你的防毒軟體。有些防毒軟體會把交出內容的程式列為「受影響的項目」。LycanZip 自己的訊息會指出真正被回報的檔案。

安裝程式、可攜版還是 Store 版？

安裝程式最簡單，而且能自己更新。可攜版把設定放在程式旁邊（適合隨身碟）。Store 版由 Windows 更新。

可以同時裝 Store 版和其他版本嗎？

可以，但裝一份就夠了。裝了 Store 版時，右鍵選單與檔案類型由 Store 版提供：安裝程式、zip 與可攜版啟動時會把自己的關掉，檔案總管只會顯示一個 LycanZip，並提示一次。每一份的設定各自獨立。只想保留一份，就到設定 → 應用程式 → 已安裝的應用程式移除另一份（可攜版直接刪掉資料夾即可）。

檔案總管的選單在哪裡？

在「設定 → 檔案總管」開啟。在 Windows 10 上，它們在右鍵選單裡。在 Windows 11 上，安裝程式與 zip 版把它們放在「顯示更多選項」裡（或按 Shift+F10）；只有 Store 版會顯示在新式的第一層選單。每個項目都可以關掉。另外還有按住右鍵拖曳的選單。

為什麼 Windows 11 新式選單只有 Store 版有？

Windows 11 只讓簽章過的套件把項目加進新式的第一層選單。只有 Store 版有簽章（由 Store 簽），安裝程式與 zip 版沒有，因為程式碼簽章憑證要花錢，而 LycanZip 是免費的。它們改用傳統選單，項目相同。

怎麼讓 LycanZip 來開啟壓縮檔？

在「設定 → 檔案總管」註冊檔案類型，再到「Windows 設定 → 應用程式 → 預設應用程式」選一次 LycanZip。Windows 不允許程式自己設成預設。

LycanZip 能開啟與建立哪些格式？

開啟：7-Zip 能讀的都行：zip、7z、rar（含分卷）、tar、gz、xz、bz2、iso、cab、wim 等。建立：zip、7z、tar、tar.gz、tar.xz、tar.bz2、iso。RAR 只能解壓縮：使用 7-Zip 程式碼的程式不能寫出 RAR 格式。

舊 zip 檔裡的檔名是亂碼。

LycanZip 會自動偵測 Big5、GBK、Shift-JIS、EUC-KR 與 UTF-8。如果猜錯了，用壓縮檔檢視右上角的按鈕選擇編碼。

我的密碼安全嗎？忘記密碼能找回來嗎？

zip 預設使用 AES-256，7z 還能連檔名一起加密。LycanZip 不會儲存或傳送密碼。忘記的密碼無法找回。

LycanZip 會透過網路傳送東西嗎？

不會傳送任何關於你或你的檔案的資料。請見隱私權政策。

「在 VirusTotal 查詢」做了什麼？檔案會被上傳嗎？

只會送出 SHA-256（放在網址裡），並在瀏覽器開啟該雜湊值的 VirusTotal 頁面。檔案絕不會被上傳。如果 VirusTotal 不認得這個雜湊值，只代表沒有人上傳過一模一樣的檔案，不代表檔案安全。

有東西不能用。要去哪裡回報？

到 GitHub 開一個 issue，並附上 lycanzip-cli info 的輸出（版本、設定位置、記錄資料夾）。
