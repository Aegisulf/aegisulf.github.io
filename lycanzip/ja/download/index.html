新しい Windows 11 の右クリック メニューに対応した唯一の版です。署名済みで、Windows が更新します。

動作環境

  • Windows 10 バージョン 1809 以降、または Windows 11（64 ビット）。
  • 他にインストールするものはありません。必要なものはすべてパッケージに含まれています。
  • 約 70 MB のディスク容量。

winget を使う

Windows のパッケージ マネージャー winget の場合：

winget install Aegisulf.LycanZip

ダウンロードの確認

各ファイルの SHA-256 は上のボタンの下（とリリース ページ）に表示されています。ダウンロードしたフォルダーで PowerShell を開き、次を実行します。

Get-FileHash .\LycanZip-1.1.1-Setup.exe -Algorithm SHA256

値は上のものと一致するはずです。一致しない場合はファイルを削除して、もう一度ダウンロードしてください。

LycanZip でも確認できます。ファイルを右クリックして ハッシュ値を計算… を選び、上の値を貼り付けてください。

「Windows によって PC が保護されました」（SmartScreen）

証明書で署名されているのは Store 版だけで、Windows は見かける機会の少ないプログラムに警告を出します。ファイルに問題があるという意味ではありません。上の SHA-256 を確認してから、詳細情報、実行 の順にクリックしてください。

展開したファイルを Windows がブロックする場合は、先に zip を右クリックして プロパティ を選び、許可する をオンにしてください。

Microsoft Store 版

同じプログラムの Store パッケージで、署名済み、更新は Windows が行います。新しい Windows 11 の右クリック メニューに対応した唯一の版です。Windows はこれを署名済みパッケージにしか許可していません。

アンインストール

インストーラー版：設定 → アプリ。zip 版：フォルダーを削除します（標準 zip は %LOCALAPPDATA%\LycanZip も）。エクスプローラーのメニューやファイルの関連付けをオンにしていた場合は、先に LycanZip の設定でオフにしてください。Store 版：設定 → アプリ で削除します。
