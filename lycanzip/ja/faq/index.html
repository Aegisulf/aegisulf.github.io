よくある質問

「Windows によって PC が保護されました」と表示されます。ダウンロードは安全ですか？

コード署名があるのは Store 版だけで、SmartScreen は見かける機会の少ないプログラムに警告を出します。ダウンロードしたファイルの SHA-256 を確認し（方法）、詳細情報 → 実行 を選んでください。ソース コードはすべて公開されています。

スキャン後、ウイルス対策ソフトが「lycanzip-cli.exe」を「影響を受ける項目」として表示します。LycanZip は感染していますか？

いいえ。圧縮ファイルをスキャンするとき、LycanZip は Windows の Antimalware Scan Interface（AMSI）を通じて各ファイルの内容をウイルス対策ソフトに渡します。ウイルス対策ソフトによっては、内容を渡したプログラムの名前を「影響を受ける項目」として表示します。実際に報告されたファイルは LycanZip 自身のメッセージに表示されます。

インストーラー、ポータブル、Store のどれがよいですか？

インストーラーは手軽で、自動更新もできます。ポータブルは設定をプログラムの隣に保存します（USB メモリ向け）。Store 版は Windows が更新します。

Store 版と他の版を同時に使えますか？

使えますが、1 つで十分です。Store 版がインストールされていると、右クリック メニューとファイルの種類は Store 版が提供します。インストーラー版、zip 版、ポータブル版は起動時に自分の分をオフにするので、エクスプローラーには LycanZip が 1 つだけ表示され、そのことを一度だけお知らせします。設定はコピーごとに別々です。1 つだけ残すには、もう一方を 設定 → アプリ → インストールされているアプリ で削除してください（ポータブルのフォルダーは削除するだけです）。

エクスプローラーのメニュー項目はどこにありますか？

LycanZip の 設定 → エクスプローラー でオンにします。Windows 10 では右クリック メニューに表示されます。Windows 11 では、インストーラー版と zip 版は その他のオプションを確認（または Shift+F10）の中に表示され、新しい最上位メニューに表示されるのは Store 版だけです。項目はそれぞれオフにできます。右ドラッグ メニューもあります。

新しい Windows 11 メニューが Store 版だけなのはなぜですか？

Windows 11 は、新しい最上位メニューへの項目追加を署名済みパッケージにしか許可しません。署名があるのは Store 版だけ（Store 自身が署名）です。コード署名証明書は有料で、LycanZip は無料のため、インストーラー版と zip 版には署名がありません。これらの版は従来のメニューを使い、項目は同じです。

圧縮ファイルを LycanZip で開くようにするには？

LycanZip の 設定 → エクスプローラー でファイルの種類を登録し、Windows の設定 → アプリ → 既定のアプリ で LycanZip を一度選んでください。Windows は、プログラムが自分を既定に設定することを許可していません。

どの形式を開けますか？作成できますか？

開ける形式：7-Zip が読めるものすべて（zip、7z、rar（分割を含む）、tar、gz、xz、bz2、iso、cab、wim など）。作成できる形式：zip、7z、tar、tar.gz、tar.xz、tar.bz2、iso。RAR は展開のみです。7-Zip のコードを使うプログラムは RAR 形式を書き込めません。

古い zip ファイルのファイル名が文字化けします。

LycanZip は Big5、GBK、Shift-JIS、EUC-KR、UTF-8 を自動で判別します。判別を誤った場合は、圧縮ファイル画面の右上のボタンでエンコードを選んでください。

パスワードは安全ですか？忘れたパスワードは復元できますか？

zip は既定で AES-256 を使い、7z はファイル名も暗号化できます。LycanZip はパスワードをどこにも送信せず、保存するのは指定されたときだけです。保存したパスワードは Windows アカウント用に暗号化され、マスター パスワードも設定できます。忘れたパスワードは復元できません。

LycanZip はインターネットに何か送信しますか？

あなたやあなたのファイルに関することは何も送信しません。プライバシー ポリシーをご覧ください。

「VirusTotal で調べる」は何をしますか？ファイルはアップロードされますか？

送られるのは SHA-256 だけで、Web アドレスの一部として渡され、そのハッシュの VirusTotal ページがブラウザーで開きます。ファイルはアップロードされません。VirusTotal がそのハッシュを知らなくても、同じファイルを誰もアップロードしていないだけで、安全という意味ではありません。

うまく動きません。どこに報告すればよいですか？

GitHub で issue を作成し、lycanzip-cli info の出力（バージョン、設定の場所、ログ フォルダー）を添えてください。
