プライバシー ポリシー

最終更新：2026 年 11 月 1 日。LycanZip プログラム（インストーラー、zip パッケージ、Microsoft Store 版）とこの Web サイトに適用されます。これは英語版の翻訳です。相違がある場合は英語版が優先します。

概要

LycanZip は個人データを収集せず、サーバーに保存せず、販売も共有もしません。テレメトリ、広告、追跡、アカウントはありません。完全にオフラインで動作します。

PC に残るもの

  • 設定とテンプレート：選択した内容（テーマ、言語、圧縮テンプレート、最近使ったフォルダー）は PC 上のファイルに保存されます。場所はプログラムのフォルダー（ポータブル）または %LOCALAPPDATA%\LycanZip（標準と Store）です。
  • 保存したパスワード：保存を選んだパスワードだけが、Windows アカウント用に暗号化され（マスター パスワードも設定可能）、PC 上のファイルに保存されます。どこにも送信されません。
  • ログ ファイル：プログラムの動作の短い記録（エラー、バージョン）です。使うのはファイル名だけで、完全なパスは、完全なパス付きの詳細ログをご自身でオンにした場合にのみ書き込まれます。どこにも送信されません。読むことも削除することもできます（場所は lycanzip-cli info で確認できます）。
  • クラッシュ レポート：プログラムがクラッシュすると PC にレポートを書き込み、必要なら不具合報告に添付できます。何もアップロードされません。
  • 一時ファイル：圧縮ファイルから開いたファイルは一時フォルダーに展開され、後で削除されます。

あなたのファイル

LycanZip は指示されたファイルを読み書きします。ファイルをアップロードしたり、名前や内容をどこかに送信したりしません。ウイルス スキャンを使うと、ファイルの内容は Windows の Antimalware Scan Interface を通じて PC にインストールされたウイルス対策ソフトに渡されます。そのソフトの動作については提供元の説明をご覧ください。

ネットワーク リクエスト

LycanZip が自分からネットワーク リクエストを行うことはありません。例外は任意の 1 つ、新しいバージョンの確認だけです。オンにすると（既定ではオフ。Microsoft Store 版は確認せず、Store が更新します）、最新のバージョン番号を示す小さな公開ファイル aegisulf.com/lycanzip/latest.json をダウンロードします。リクエストに識別子や設定、PC やファイルに関する情報は含まれません。インストーラーでインストールしたコピーでこの確認をオンにしている場合は、更新自体も aegisulf.com/lycanzip/updates/ からダウンロードして署名を確認し、選択したときにのみインストールします。このリクエストも上と同様に匿名です。他の Web リクエストと同様に、ファイルをホストするサーバー（GitHub Pages）は自身のログでリクエストの IP アドレスを確認できます。LycanZip はそのログにアクセスできません。

2 つ目はご自身で開始するものです：VirusTotal で調べる（その他のオプション、圧縮ファイル内のファイルのメニュー、ハッシュ値ウィンドウにあります）。LycanZip はファイルの SHA-256 を計算し、そのハッシュの virustotal.com のページをブラウザーで開きます。アドレスに含まれるのはハッシュだけで、ファイルはアップロードされず、VirusTotal のアカウントや API も使いません。VirusTotal とブラウザーには、他の Web ページを開くときと同じようにリクエストが見えます。VirusTotal がそのハッシュを知らなくても、ファイルが安全という意味ではありません。

この Web サイト

このサイトには Cookie、アクセス解析、第三者のスクリプトやフォントはありません。ページは GitHub Pages から配信され、GitHub のプライバシー ステートメントに記載のとおり技術的なログが保持されることがあります。

お子様について

LycanZip はお子様を含め、誰からもデータを収集しません。
