Licencias y créditos

Esta es una traducción de la versión en inglés; si hay diferencias, prevalece la versión en inglés.

LycanZip

LycanZip es software libre con licencia MIT. Puedes usarlo, copiarlo, cambiarlo y compartirlo, también con fines comerciales, siempre que el texto de la licencia lo acompañe. Se ofrece sin garantía.

7-Zip

La compresión y la extracción las realiza el motor de 7-Zip de Igor Pavlov, cargado como una biblioteca independiente (7z.dll, incluida en los paquetes junto con sus textos de licencia). 7-Zip tiene licencia GNU LGPL, y el código que lee archivos RAR lleva la «restricción de unRAR»: se puede usar para leer archivos RAR, pero no para desarrollar software que cree archivos RAR. LycanZip solo extrae archivos RAR. LycanZip no está hecho, respaldado ni soportado por los autores de 7-Zip.

Windows App SDK y WinUI 3

La interfaz usa Windows App SDK y WinUI 3 de Microsoft (licencia MIT). «Windows», «Microsoft Store» y los demás nombres de productos de este sitio pertenecen a sus propietarios.

La lista completa

La lista completa de los componentes y sus licencias está en el archivo THIRD_PARTY.md y la carpeta licenses de cada paquete, y en el repositorio de código fuente.
