Questions fréquentes

Windows affiche « Windows a protégé votre ordinateur ». Le téléchargement est-il sûr ?

Seule la version Store a une signature de code, et SmartScreen avertit pour les programmes qu’il voit rarement. Vérifiez le SHA-256 de votre téléchargement sur la page de la version (comment faire), puis choisissez Informations complémentaires → Exécuter quand même. Tout le code source est public.

Mon antivirus signale « lycanzip-cli.exe » comme élément concerné après une analyse. LycanZip est-il infecté ?

Non. Quand vous analysez une archive, LycanZip transmet le contenu de chaque fichier à votre antivirus via l’interface Antimalware Scan Interface (AMSI) de Windows. Certains antivirus indiquent alors comme élément concerné le programme qui l’a transmis. Le message de LycanZip lui-même indique le fichier réellement signalé.

Programme d’installation, portable ou Store ?

Le programme d’installation est le choix facile et peut se mettre à jour seul. La version portable garde ses paramètres à côté du programme (pour une clé USB). La version Store est mise à jour par Windows.

Puis-je avoir la version Store et une autre en même temps ?

Oui, mais une seule suffit. Quand la version Store est installée, elle fournit le menu contextuel et les types de fichiers : les versions installée, zip et portable désactivent les leurs au démarrage, si bien que l’Explorateur de fichiers n’affiche LycanZip qu’une fois, et elles le signalent une fois. Chaque copie garde ses propres paramètres. Pour n’en garder qu’une, supprimez l’autre dans Paramètres → Applications → Applications installées (un dossier portable se supprime simplement).

Où sont les entrées dans le menu de l’Explorateur ?

Activez-les dans LycanZip, sous Paramètres → Explorateur de fichiers. Sous Windows 10, elles sont dans le menu contextuel. Sous Windows 11, les versions installée et zip les affichent sous Afficher d’autres options (ou Shift+F10) ; seule la version Store les affiche dans le nouveau menu principal. Chaque entrée peut être désactivée. Il existe aussi un menu au glisser avec le bouton droit.

Pourquoi le nouveau menu de Windows 11 n’est-il que dans la version Store ?

Windows 11 ne permet qu’à un package signé d’ajouter des entrées à son nouveau menu principal. Seule la version Store est signée (par le Store lui-même) ; les versions installée et zip ne le sont pas, car un certificat de signature de code est payant et LycanZip est gratuit. Elles utilisent le menu classique, avec les mêmes entrées.

Comment faire ouvrir les archives par LycanZip ?

Enregistrez les types de fichiers dans LycanZip, sous Paramètres → Explorateur de fichiers, puis choisissez LycanZip une fois dans Paramètres Windows → Applications → Applications par défaut. Windows ne laisse pas un programme se définir lui-même par défaut.

Quels formats LycanZip peut-il ouvrir et créer ?

Ouvrir : tout ce que 7-Zip lit : zip, 7z, rar (y compris fractionné), tar, gz, xz, bz2, iso, cab, wim et d’autres. Créer : zip, 7z, tar, tar.gz, tar.xz, tar.bz2, iso. RAR ne peut être qu’extrait : les programmes qui utilisent le code de 7-Zip ne peuvent pas écrire le format RAR.

Les noms de fichiers d’un ancien zip sont illisibles.

LycanZip détecte seul Big5, GBK, Shift-JIS, EUC-KR et UTF-8. S’il s’est trompé, choisissez l’encodage avec le bouton en haut à droite de la vue de l’archive.

Mon mot de passe est-il en sécurité ? Un mot de passe perdu peut-il être récupéré ?

zip utilise AES-256 par défaut, et 7z peut aussi chiffrer les noms de fichiers. LycanZip n’envoie jamais de mots de passe et n’en enregistre un que si vous le demandez : ceux enregistrés sont chiffrés pour votre compte Windows, avec un mot de passe principal facultatif. Un mot de passe perdu ne peut pas être récupéré.

LycanZip envoie-t-il quelque chose sur Internet ?

Rien sur vous ni sur vos fichiers. Voir la politique de confidentialité.

Que fait « Rechercher sur VirusTotal » ? Le fichier est-il envoyé ?

Seul le SHA-256 est envoyé, dans l’adresse web, et la page VirusTotal de ce hachage s’ouvre dans votre navigateur. Le fichier n’est jamais envoyé. Si VirusTotal ne connaît pas le hachage, cela signifie seulement que personne n’a envoyé ce fichier précis : cela ne signifie pas qu’il est sûr.

Quelque chose ne fonctionne pas. Où le signaler ?

Ouvrez un issue sur GitHub et ajoutez la sortie de lycanzip-cli info (version, emplacement des paramètres, dossier des journaux).
