Configuration requise

  • Windows 10 version 1809 ou ultérieure, ou Windows 11 ; 64 bits.
  • Rien d’autre à installer. Tout ce dont LycanZip a besoin est dans le package.
  • Environ 70 Mo d’espace disque.

Avec winget

winget, le gestionnaire de packages de Windows :

winget install Aegisulf.LycanZip

Vérifier votre téléchargement

Le SHA-256 de chaque fichier figure sous son bouton (et sur la page de la version). Dans PowerShell, dans le dossier du téléchargement :

Get-FileHash .\LycanZip-1.1.1-Setup.exe -Algorithm SHA256

La valeur doit correspondre à celle du haut. Sinon, supprimez le fichier et téléchargez-le de nouveau.

LycanZip peut aussi le faire : cliquez avec le bouton droit sur le fichier, choisissez Calculer les valeurs de hachage… et collez la valeur du haut.

« Windows a protégé votre ordinateur » (SmartScreen)

Seule la version Store est signée avec un certificat, et Windows avertit pour les programmes qu’il voit rarement. Cela ne signifie pas que le fichier est dangereux. Après avoir vérifié le SHA-256, cliquez sur Informations complémentaires, puis sur Exécuter quand même.

Si Windows bloque les fichiers décompressés, cliquez d’abord avec le bouton droit sur le zip, choisissez Propriétés et cochez Débloquer.

La version Microsoft Store

Le même programme sous forme de package Store, signé et mis à jour par Windows. C’est la seule version avec le nouveau menu contextuel de Windows 11 : Windows ne l’autorise que pour les packages signés.

Désinstaller

Programme d’installation : Paramètres → Applications. Zip : supprimez le dossier (et %LOCALAPPDATA%\LycanZip pour le zip standard). Si vous avez activé le menu de l’Explorateur ou les associations de fichiers, désactivez-les d’abord dans les paramètres. Version Store : supprimez-la dans Paramètres → Applications.
