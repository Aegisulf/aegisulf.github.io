Politique de confidentialité

Dernière mise à jour : 1/11/2026. S’applique au programme LycanZip (le programme d’installation, les packages zip et la version Microsoft Store) et à ce site web. Ceci est une traduction de la version anglaise ; en cas de divergence, la version anglaise prévaut.

En bref

LycanZip ne collecte, ne stocke sur un serveur, ne vend et ne partage aucune donnée personnelle. Il n’a ni télémétrie, ni publicité, ni suivi, ni compte. Il fonctionne entièrement hors ligne.

Ce qui reste sur votre ordinateur

  • Paramètres et modèles : vos choix (thème, langue, modèles de compression, dossiers récents) sont enregistrés dans un fichier sur votre ordinateur, dans le dossier du programme (portable) ou dans %LOCALAPPDATA%\LycanZip (standard et Store).
  • Mots de passe enregistrés : uniquement ceux que vous choisissez d’enregistrer, chiffrés pour votre compte Windows (avec un mot de passe principal facultatif) dans un fichier sur votre ordinateur. Ils ne sont jamais envoyés nulle part.
  • Fichier journal : un court journal de ce qu’a fait le programme (erreurs, versions). Il n’utilise que les noms de fichiers ; les chemins complets ne sont écrits que si vous activez vous-même le journal détaillé avec chemins complets. Il n’est jamais envoyé nulle part. Vous pouvez le lire et le supprimer (lycanzip-cli info indique où il se trouve).
  • Rapports de plantage : si le programme plante, il écrit un rapport sur votre ordinateur, que vous pouvez joindre à un signalement de bug si vous le souhaitez. Rien n’est envoyé.
  • Fichiers temporaires : les fichiers ouverts depuis une archive sont extraits dans un dossier temporaire puis supprimés.

Vos fichiers

LycanZip lit et écrit les fichiers que vous lui demandez. Il ne les envoie pas et ne transmet ni leurs noms ni leur contenu. Si vous utilisez l’analyse antivirus, le contenu des fichiers est transmis à l’antivirus installé sur votre ordinateur via l’interface Antimalware Scan Interface de Windows ; ce que fait ce programme est décrit par son éditeur.

Requêtes réseau

LycanZip n’effectue aucune requête réseau de lui-même, à une exception facultative près : la recherche d’une nouvelle version. Quand elle est activée (désactivée par défaut ; la version Microsoft Store ne vérifie jamais, le Store la met à jour), le programme télécharge un petit fichier public, aegisulf.com/lycanzip/latest.json, qui indique le dernier numéro de version. La requête ne contient aucun identifiant, aucun paramètre et rien sur votre ordinateur ou vos fichiers. Une copie installée avec le programme d’installation dont cette recherche est activée télécharge aussi la mise à jour depuis aegisulf.com/lycanzip/updates/, vérifie sa signature et ne l’installe que si vous le choisissez ; la requête est aussi anonyme que la précédente. Comme pour toute requête web, le serveur qui héberge le fichier (GitHub Pages) voit l’adresse IP de la requête dans ses propres journaux ; LycanZip n’y a pas accès.

Le second cas est celui que vous lancez vous-même : Rechercher sur VirusTotal (dans Plus d’options, dans le menu d’un fichier de l’archive et dans la fenêtre des valeurs de hachage). LycanZip calcule le SHA-256 du fichier et ouvre virustotal.com dans votre navigateur à la page de ce hachage. Seul le hachage figure dans l’adresse ; le fichier n’est pas envoyé et LycanZip n’utilise ni compte ni API VirusTotal. VirusTotal et votre navigateur voient la requête comme pour toute page web que vous ouvrez. Si VirusTotal ne connaît pas le hachage, cela ne signifie pas que le fichier est sûr.

Ce site web

Le site n’a ni cookies, ni outils d’analyse, ni scripts ou polices de tiers. Ses pages sont servies par GitHub Pages, qui peut conserver des journaux techniques comme décrit dans la déclaration de confidentialité de GitHub.

Enfants

LycanZip ne collecte de données auprès de personne, y compris les enfants.
