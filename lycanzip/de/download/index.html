Voraussetzungen

  • Windows 10 Version 1809 oder neuer oder Windows 11; 64 Bit.
  • Sonst muss nichts installiert werden. Alles, was LycanZip braucht, ist im Paket.
  • Etwa 70 MB Speicherplatz.

Mit winget

winget, der Paketmanager von Windows:

winget install Aegisulf.LycanZip

Download prüfen

Der SHA-256 jeder Datei steht oben unter ihrer Schaltfläche (und auf der Release-Seite). In PowerShell, im Ordner des Downloads:

Get-FileHash .\LycanZip-1.1.1-Setup.exe -Algorithm SHA256

Der Wert muss mit dem oben übereinstimmen. Falls nicht, löschen Sie die Datei und laden Sie sie erneut herunter.

Auch LycanZip kann das: Klicken Sie mit der rechten Maustaste auf die Datei, wählen Sie Hashwerte berechnen… und fügen Sie den Wert von oben ein.

„Der Computer wurde durch Windows geschützt“ (SmartScreen)

Nur die Store-Version ist mit einem Zertifikat signiert, und Windows warnt vor Programmen, die es selten sieht. Das heißt nicht, dass die Datei schädlich ist. Prüfen Sie den SHA-256 oben und klicken Sie dann auf Weitere Informationen und Trotzdem ausführen.

Blockiert Windows entpackte Dateien, klicken Sie zuerst mit der rechten Maustaste auf das Zip, wählen Sie Eigenschaften und aktivieren Sie Zulassen.

Die Microsoft-Store-Version

Dasselbe Programm als Store-Paket, signiert und von Windows aktualisiert. Es ist die einzige Version mit dem neuen Kontextmenü von Windows 11: Windows erlaubt das nur signierten Paketen.

Deinstallieren

Installationsprogramm: Einstellungen → Apps. Zip: den Ordner löschen (beim Standard-Zip auch %LOCALAPPDATA%\LycanZip). Wenn Sie das Explorer-Menü oder Dateizuordnungen eingeschaltet haben, schalten Sie sie zuerst in den Einstellungen ab. Store-Version: unter Einstellungen → Apps entfernen.
