Datenschutzerklärung

Zuletzt aktualisiert: 1.11.2026. Gilt für das Programm LycanZip (Installationsprogramm, Zip-Pakete und Microsoft-Store-Version) und diese Website. Dies ist eine Übersetzung der englischen Fassung; bei Abweichungen gilt die englische Fassung.

Kurz gesagt

LycanZip sammelt keine personenbezogenen Daten, speichert sie nicht auf einem Server, verkauft und teilt sie nicht. Es gibt keine Telemetrie, keine Werbung, kein Tracking und keine Konten. Es funktioniert vollständig offline.

Was auf Ihrem Computer bleibt

  • Einstellungen und Vorlagen: Ihre Auswahl (Design, Sprache, Komprimierungsvorlagen, zuletzt verwendete Ordner) wird in einer Datei auf Ihrem Computer gespeichert, im Programmordner (portabel) oder in %LOCALAPPDATA%\LycanZip (Standard und Store).
  • Gespeicherte Kennwörter: nur die Kennwörter, die Sie speichern möchten, für Ihr Windows-Konto verschlüsselt (optional mit Masterkennwort) in einer Datei auf Ihrem Computer. Sie werden nie irgendwohin gesendet.
  • Protokolldatei: ein kurzes Protokoll dessen, was das Programm getan hat (Fehler, Versionen). Es enthält nur Dateinamen; vollständige Pfade werden nur geschrieben, wenn Sie das ausführliche Protokoll mit vollständigen Pfaden selbst einschalten. Es wird nie irgendwohin gesendet. Sie können es lesen und löschen (lycanzip-cli info zeigt, wo es liegt).
  • Absturzberichte: Stürzt das Programm ab, schreibt es einen Bericht auf Ihren Computer, den Sie auf Wunsch einem Fehlerbericht beifügen können. Nichts wird hochgeladen.
  • Temporäre Dateien: Aus einem Archiv geöffnete Dateien werden in einen temporären Ordner entpackt und danach entfernt.

Ihre Dateien

LycanZip liest und schreibt die Dateien, um die Sie es bitten. Es lädt sie nicht hoch und sendet weder ihre Namen noch ihren Inhalt irgendwohin. Wenn Sie den Virenscan verwenden, wird der Inhalt der Dateien über das Windows Antimalware Scan Interface an das auf Ihrem Computer installierte Virenschutzprogramm übergeben; was dieses Programm tut, beschreibt sein Hersteller.

Netzwerkanfragen

LycanZip stellt von sich aus keine Netzwerkanfragen, mit einer optionalen Ausnahme: der Suche nach einer neuen Version. Ist sie eingeschaltet (standardmäßig aus; die Microsoft-Store-Version prüft nie, der Store aktualisiert sie), lädt das Programm eine kleine öffentliche Datei herunter, aegisulf.com/lycanzip/latest.json, die die neueste Versionsnummer nennt. Die Anfrage enthält keine Kennung, keine Einstellungen und nichts über Ihren Computer oder Ihre Dateien. Eine mit dem Installationsprogramm installierte Kopie, bei der diese Suche eingeschaltet ist, lädt auch das Update selbst von aegisulf.com/lycanzip/updates/ herunter, prüft seine Signatur und installiert es nur, wenn Sie das wählen; die Anfrage ist so anonym wie die oben genannte. Wie bei jeder Webanfrage sieht der Server, der die Datei bereitstellt (GitHub Pages), die IP-Adresse der Anfrage in seinen eigenen Protokollen; LycanZip hat darauf keinen Zugriff.

Der zweite Fall ist etwas, das Sie selbst starten: Bei VirusTotal nachschlagen (unter Weitere Optionen, im Menü einer Datei im Archiv und im Fenster der Hashwerte). LycanZip berechnet den SHA-256 der Datei und öffnet virustotal.com in Ihrem Browser auf der Seite dieses Hashs. Nur der Hash ist Teil der Adresse; die Datei wird nicht hochgeladen, und LycanZip verwendet weder ein VirusTotal-Konto noch die API. VirusTotal und Ihr Browser sehen die Anfrage wie bei jeder Webseite, die Sie öffnen. Kennt VirusTotal den Hash nicht, heißt das nicht, dass die Datei sicher ist.

Diese Website

Die Website hat keine Cookies, keine Analysen und keine Skripte oder Schriften von Dritten. Ihre Seiten werden von GitHub Pages bereitgestellt, das technische Protokolle führen kann, wie in der Datenschutzerklärung von GitHub beschrieben.

Kinder

LycanZip sammelt von niemandem Daten, auch nicht von Kindern.
