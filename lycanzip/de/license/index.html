LycanZip

LycanZip ist freie Software unter der MIT-Lizenz. Sie dürfen es verwenden, kopieren, ändern und weitergeben, auch kommerziell, solange der Lizenztext dabei bleibt. Es wird ohne Gewährleistung bereitgestellt.

7-Zip

Das Packen und Entpacken übernimmt die 7-Zip-Engine von Igor Pavlov, die als separate Bibliothek geladen wird (7z.dll, zusammen mit ihren Lizenztexten in den Paketen enthalten). 7-Zip steht unter der GNU LGPL, und der Code zum Lesen von RAR-Archiven unterliegt der „unRAR-Einschränkung“: Er darf zum Lesen von RAR-Archiven verwendet werden, aber nicht, um Software zu entwickeln, die RAR-Archive erstellt. LycanZip entpackt RAR-Archive nur. LycanZip wird von den Autoren von 7-Zip weder erstellt noch empfohlen oder unterstützt.

Windows App SDK und WinUI 3

Die Oberfläche verwendet das Windows App SDK und WinUI 3 von Microsoft (MIT-Lizenz). „Windows“, „Microsoft Store“ und die anderen Produktnamen auf dieser Website gehören ihren Eigentümern.
