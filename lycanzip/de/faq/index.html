Häufige Fragen

Windows meldet „Der Computer wurde durch Windows geschützt“. Ist der Download sicher?

Nur die Store-Version ist codesigniert, und SmartScreen warnt vor Programmen, die es selten sieht. Prüfen Sie den SHA-256 Ihres Downloads anhand der Release-Seite (so geht es) und wählen Sie dann Weitere Informationen → Trotzdem ausführen. Der gesamte Quellcode ist öffentlich.

Mein Virenschutz nennt nach einem Scan „lycanzip-cli.exe“ als betroffenes Element. Ist LycanZip infiziert?

Nein. Beim Scannen eines Archivs übergibt LycanZip den Inhalt jeder Datei über das Windows Antimalware Scan Interface (AMSI) an Ihren Virenschutz. Manche Virenschutzprogramme nennen dann das Programm, das den Inhalt übergeben hat, als betroffenes Element. Die eigene Meldung von LycanZip nennt die Datei, die tatsächlich gemeldet wurde.

Installationsprogramm, portabel oder Store?

Das Installationsprogramm ist der einfache Weg und kann sich selbst aktualisieren. Die portable Version speichert ihre Einstellungen neben dem Programm (für USB-Sticks). Die Store-Version wird von Windows aktualisiert.

Kann ich die Store-Version und eine andere gleichzeitig nutzen?

Ja, aber eine genügt. Ist die Store-Version installiert, stellt sie das Kontextmenü und die Dateitypen bereit: Die Installations-, Zip- und portablen Versionen schalten ihre eigenen beim Start ab, sodass der Datei-Explorer LycanZip nur einmal zeigt, und weisen einmal darauf hin. Jede Kopie behält ihre eigenen Einstellungen. Um nur eine zu behalten, entfernen Sie die andere unter Einstellungen → Apps → Installierte Apps (einen portablen Ordner können Sie einfach löschen).

Wo sind die Einträge im Explorer-Menü?

Schalten Sie sie in LycanZip unter Einstellungen → Datei-Explorer ein. Unter Windows 10 stehen sie im Kontextmenü. Unter Windows 11 zeigen die Installations- und Zip-Versionen sie unter Weitere Optionen anzeigen (oder Shift+F10); nur die Store-Version zeigt sie im neuen Hauptmenü. Jeder Eintrag lässt sich abschalten. Auch ein Menü beim Ziehen mit der rechten Maustaste gibt es.

Warum gibt es das neue Windows-11-Menü nur in der Store-Version?

Windows 11 erlaubt nur einem signierten Paket, Einträge im neuen Hauptmenü hinzuzufügen. Nur die Store-Version ist signiert (vom Store selbst); die Installations- und Zip-Versionen nicht, denn ein Codesignaturzertifikat kostet Geld und LycanZip ist kostenlos. Sie nutzen stattdessen das klassische Menü mit denselben Einträgen.

Wie öffnet LycanZip meine Archive?

Registrieren Sie die Dateitypen in LycanZip unter Einstellungen → Datei-Explorer und wählen Sie LycanZip einmal unter Windows-Einstellungen → Apps → Standard-Apps. Windows lässt nicht zu, dass sich ein Programm selbst zum Standard macht.

Welche Formate kann LycanZip öffnen und erstellen?

Öffnen: alles, was 7-Zip liest: zip, 7z, rar (auch geteilt), tar, gz, xz, bz2, iso, cab, wim und mehr. Erstellen: zip, 7z, tar, tar.gz, tar.xz, tar.bz2, iso. RAR kann nur entpackt werden: Programme, die 7-Zip-Code verwenden, dürfen das RAR-Format nicht schreiben.

Die Dateinamen in einer alten zip-Datei sind unleserlich.

LycanZip erkennt Big5, GBK, Shift-JIS, EUC-KR und UTF-8 von selbst. Lag es falsch, wählen Sie die Codierung mit der Schaltfläche oben rechts in der Archivansicht.

Ist mein Kennwort sicher? Lässt sich ein verlorenes Kennwort wiederherstellen?

zip verwendet standardmäßig AES-256, und 7z kann auch die Dateinamen verschlüsseln. LycanZip sendet Kennwörter nirgendwohin und speichert eines nur, wenn Sie es wünschen: Gespeicherte Kennwörter werden für Ihr Windows-Konto verschlüsselt, optional mit einem Masterkennwort. Ein verlorenes Kennwort lässt sich nicht wiederherstellen.

Sendet LycanZip etwas ins Internet?

Nichts über Sie oder Ihre Dateien. Siehe Datenschutzerklärung.

Was macht „Bei VirusTotal nachschlagen“? Wird die Datei hochgeladen?

Nur der SHA-256 wird gesendet, als Teil der Webadresse, und die VirusTotal-Seite dieses Hashs öffnet sich in Ihrem Browser. Die Datei wird nie hochgeladen. Kennt VirusTotal den Hash nicht, heißt das nur, dass niemand genau diese Datei hochgeladen hat: Es heißt nicht, dass sie sicher ist.

Etwas funktioniert nicht. Wo melde ich das?

Eröffnen Sie ein Issue auf GitHub und fügen Sie die Ausgabe von lycanzip-cli info bei (Version, Ort der Einstellungen, Protokollordner).
