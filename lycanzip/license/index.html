The packing and unpacking is done by the 7-Zip engine by Igor Pavlov, loaded as a separate library (7z.dll, bundled in the packages together with its license texts). 7-Zip is licensed under the GNU LGPL, and the code that reads RAR archives carries the “unRAR restriction”: it may be used to read RAR archives, but not to build software that creates RAR archives. LycanZip only extracts RAR archives. LycanZip is not made, endorsed or supported by the authors of 7-Zip.
