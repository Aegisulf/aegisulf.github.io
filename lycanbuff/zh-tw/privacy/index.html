隱私權政策

最後更新：2026-11-04。適用於 Android 與 Windows 版的 LycanBuff App 以及本網站。若本中文版與英文版有出入，以英文版為準。

摘要

LycanBuff 不收集、不出售、不分享任何個人資料。開發者沒有伺服器，不會收到你的資料。App 沒有廣告、分析、追蹤，也沒有當機回報服務，完全可以離線使用。登入是選用的，只用來把備份存到你自己的 Google 雲端硬碟或 Microsoft OneDrive。

留在你裝置上的資料

  • 訓練資料：動作、範本、訓練、各組紀錄與設定，存在 App 私有儲存空間中的資料庫。
  • 還原之前：App 會在私有儲存空間保留一份目前資料的副本，讓你可以復原上一次的還原。
  • 你匯出或匯入的檔案：備份與 CSV 匯出存到你選擇的位置；匯入的 Strong CSV 只在你的裝置上讀取。
  • 通知：休息計時的提醒與「訓練進行中」通知都在裝置上排程，不會傳送到任何通知伺服器。

Google 雲端硬碟備份（選用）

只有在你選擇「備份到 Google 雲端硬碟」並以 Google 帳號登入後，LycanBuff 才會使用 Google 使用者資料，方式如下：

  • 存取的資料：你的電子郵件地址（用來顯示連結的是哪個帳號），以及 LycanBuff 自己在你雲端硬碟中建立的檔案（drive.file 權限）。App 看不到、也無法開啟你雲端硬碟中的其他任何檔案。
  • 使用方式：把 LycanBuff 訓練資料的備份檔上傳到你雲端硬碟中名為 LycanBuff 的資料夾（登入後立刻一次、每次訓練結束後，以及你選擇「立即備份」時），還原時列出並下載備份，並刪除最舊的備份，只保留最新的 10 份。
  • 儲存方式：備份存在你自己的 Google 雲端硬碟。登入用的權杖只存在你的裝置上，放在系統的安全儲存區（Android Keystore、Windows 資料保護）；不會寫進備份，也不會傳給開發者。
  • 分享：Google 使用者資料不會分享或轉移給任何人。App 只連線到 Google 自己的服務（accounts.google.com、oauth2.googleapis.com、www.googleapis.com），沒有任何其他對象會收到這些資料。

LycanBuff 對於從 Google API 取得之資訊的使用與轉移，遵守 Google API 服務使用者資料政策，包括其中的「有限使用」規定。

停止使用：在 App 設定中選擇「登出」，會刪除裝置上的權杖並撤銷 App 的存取權。你也可以在 myaccount.google.com/connections 移除 LycanBuff。要刪除備份，請刪除你 Google 雲端硬碟中的 LycanBuff 資料夾。

Microsoft OneDrive 備份（選用）

只有在你選擇「備份到 OneDrive」並以 Microsoft 帳號登入後，LycanBuff 才會使用你的 Microsoft 帳號，方式如下。同一時間只會登入一個雲端硬碟。

  • 存取的資料：你的帳號名稱與電子郵件地址（用來顯示連結的是哪個帳號），以及你 OneDrive 中 App 專屬的資料夾（Apps/LycanBuff，Files.ReadWrite.AppFolder 權限）。App 看不到、也無法開啟你 OneDrive 中的其他任何檔案。
  • 使用方式：與上述 Google 雲端硬碟相同：把備份檔上傳到這個資料夾，還原時列出並下載備份，並刪除最舊的備份，只保留最新的 10 份。
  • 儲存方式：備份存在你自己的 OneDrive；登入用的權杖只存在你的裝置上，放在系統的安全儲存區，不會傳給開發者。
  • 分享：資料不會分享給任何人。App 只連線到 Microsoft 自己的服務（login.microsoftonline.com、graph.microsoft.com，以及下載用的 my.microsoftpersonalcontent.com）。

停止使用：在 App 設定中選擇「登出」會刪除裝置上的權杖；並請到 account.live.com/consent/Manage 移除 LycanBuff。要刪除備份，請刪除你 OneDrive 中的 Apps/LycanBuff 資料夾。

權限

  • 通知與鬧鐘（Android）：用於休息計時的提醒。
  • 保持螢幕開啟：訓練進行中，且你沒有關閉這個設定時。
  • 網際網路：只用於上述的 Google 雲端硬碟或 OneDrive 備份。

本網站

本網站沒有 Cookie、沒有分析工具，也沒有第三方的程式碼或字型。網頁由 GitHub Pages 提供，GitHub 可能依 GitHub 隱私權聲明 保留技術性紀錄。

兒童

LycanBuff 不收集任何人的資料，包括兒童。
